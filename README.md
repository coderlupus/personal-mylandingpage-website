# 🚀 Personal Portfolio Website

A modern, high-performance portfolio website built to showcase skills, projects, and professional experience. Designed with a focus on aesthetics, responsiveness, and user experience.

## ✨ Features

- **🎨 Modern & Responsive Design**: Built with specific attention to detail, ensuring a premium look on all devices.
- **⚡ High Performance**: Powered by Vite for lightning-fast HMR and build times.
- **🔧 Interactive UI**: components built with Radix UI and Shadcn UI for accessible and robust interactions.
- **🎭 Smooth Animations**: Integrated with Lottie and Tailwind CSS animations for a dynamic feel.
- **📱 Mobile First**: Fully responsive layouts that adapt seamlessly from mobile to desktop.
- **📝 Form Handling**: Robust form validation using React Hook Form and Zod.

## 🛠️ Technology Stack

This project leverages the latest web technologies:

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/) (based on Radix UI)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Lottie React](https://lottiefiles.com/web-player)
- **Forms**: [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)
- **Charts**: [Recharts](https://recharts.org/)

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) (usually comes with Node.js)

### Installation

1. **Clone the repository**
   ```bash
   git clone <YOUR_GIT_URL>
   cd personal-myportifolio-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:8080` (or the port shown in your terminal) to view the application.

## 📜 Scripts

- `npm run dev`: Starts the development server with hot module replacement.
- `npm run build`: Builds the application for production optimization.
- `npm run preview`: Locally previews the production build.
- `npm run lint`: Runs ESLint to check for code quality and errors.
